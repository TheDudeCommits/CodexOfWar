# P10 Round006 — Nyra Kestrel Concept Preflight

This folder contains a frozen, original 2D concept preflight for **Nyra Kestrel, Stormglass Warden** and her **Stormglass Odachi**.

Accepted assets:

- `P10_Round006_NyraKestrel_Turnaround_v1.png` — four-view character turnaround.
- `P10_Round006_StormglassOdachi_v1.png` — orthographic weapon and grip-detail sheet.
- `P10_Round006_NyraKestrel_CombatGrip_v1.png` — full-body two-hand contact proof generated from the accepted character and weapon images.

One rejected combat-grip iteration is retained under `Iterations/` with an honest reason in `P10_Round006_ConceptReceipt.json`.

No benchmark, God of War, franchise, user reference, or other third-party/proprietary input pixels were supplied. The private benchmark archive and the unproven Round004 concept were neither inspected nor used. The only edit inputs were images generated inside this Round006 concept build.

These PNGs are **2D concept preflight only**. They are not 3D assets and make no claim of game readiness: no mesh topology, dimensions, rig, UVs, textures, collision, animation, LODs, performance, or production implementation has been established.

The concept is frozen for a separate fresh originality, consistency, anatomy, weapon-function, rights, and publication critic. The JSON receipt is the authoritative prompt, hash, input-lineage, rejection, limitation, and inspection record.
