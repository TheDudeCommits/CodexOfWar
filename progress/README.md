# Codex of War progress ledger

This Vinext site presents the checked-in production ledger, latest Unity
capture, canonical review contract, acceptance gate, and builder/critic round
history for Codex of War.

## Local development

```bash
npm ci
npm run dev
```

The development server uses [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
npm test
```

`npm test` server-renders the page, verifies the complete P00–P25 ledger, and
checks that the filed PNG SHA-256 and manifest metadata match
`public/data/codex-of-war.json`.

## Data ownership

- `public/data/codex-of-war.json` is the production ledger.
- `public/data/P00-round-001-manifest.json` is the immutable round manifest.
- `public/data/capture-manifest-latest.json` points readers to the latest filed
  capture.
- `public/captures/P00/round-001/S01_Explore.png` is generated by Unity, not by
  the site.

The site never hosts the local benchmark originals. It names benchmark shots by
ID only.
